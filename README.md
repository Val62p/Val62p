# Night Key

Petit prototype de jeu d'horreur en HTML/CSS/JS.

## Lancer le jeu sur PC

Vous pouvez ouvrir directement `index.html` dans votre navigateur, ou utiliser un petit serveur local :

```bash
python -m http.server 8000
```

Puis ouvrez :

```
http://127.0.0.1:8000/index.html
```

Si la page affiche « Not Found », vérifiez que vous lancez la commande **dans le dossier du projet** contenant `index.html`.
